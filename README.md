# CHADOO — Interactive Fruit Tea Brand Website

A cinematic, responsive website created as a personal concept project for CHADOO, a fictional fruit tea brand.

**[View Live Website](https://jiashiang-dev.github.io/chadoo-website/)**

## Project Overview

CHADOO explores how visual storytelling, interactive motion, and minimal design can create a distinctive digital experience for a modern beverage brand.

The website contains seven sections, combining product presentation, brand storytelling, lifestyle imagery, and conceptual retail spaces.

## Website Features

- Seven-section website experience
- Scroll-controlled cinematic hero video
- Interactive fruit tea product previews
- Ingredient and brand storytelling
- Three lifestyle moments: Morning, Afternoon, and Night
- Switchable conceptual CHADOO spaces
- Responsive desktop and mobile layouts
- Smooth transitions and interactive navigation

## Technology

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Scroll-based interactions
- GitHub Pages
